# Contact-React

# 📇 Gestionnaire de Contacts - React

## Description

Ce projet est une application web de gestion de contacts développée avec **React** (via Vite). Elle permet de gérer un carnet d'adresses numérique de manière intuitive.

## Fonctionnalités (CRUD)

L'application remplit les objectifs suivants:

* **Ajout** : Créer un contact avec prénom, nom, email et téléphone.


* **Affichage** : Visualiser la liste complète des contacts enregistrés.


* **Modification** : Éditer les informations d'un contact existant.


* **Suppression** : Retirer un contact de la liste.



## Technologies utilisées

* **Frontend** : React.js (Vite).


* **Style** : CSS3.


* **Backend** : Connexion prévue à une API Node.js.



## Structure du projet

L'architecture suit la structure demandée dans l'exercice:

```text
src/
├── App.jsx             # Composant principal (Logique et State)
├── App.css             # Styles de l'application
├── components/         # Dossier des composants réutilisables
│   ├── ContactForm.jsx # Formulaire d'ajout/modification
│   ├── ContactList.jsx # Conteneur de la liste
│   └── ContactItem.jsx # Affichage d'un contact individuel

```
